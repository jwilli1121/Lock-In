Lock-In: Personal Growth Dashboard
Lock-In is a browser-based personal growth dashboard that brings habit tracking, health metrics, workout logging, personal finance, achievements, and progress analytics into one local-first application.

The project was created through AI-assisted development. I defined the product vision, requested and prioritized features, designed the workflows, tested each version, identified problems, and directed the application’s development through more than 20 major iterations.

Life Score
The Life Score is a motivational score from 0 to 100. It combines five categories:

Habits: 30%
Health: 20%
Workouts: 20%
Finance: 20%
Consistency: 10%
The Life Score is intended as a personal progress indicator. It is not a medical, financial, or professional assessment.

Privacy and Data Storage
Lock-In stores application data in the browser’s Local Storage.

This means:

Data is not automatically uploaded to a server.
Data may be different on each browser or device.
Clearing browser data may remove saved information.
Exported backups should be created regularly.
The public demo should not be used to store sensitive financial, health, or personal information.
